## Base URLs

| Environment | Base URL | Keys |
| --- | --- | --- |
| Production | `https://api.apiculture.example/v1` | `ak_live_…` |
| Sandbox | `https://sandbox.api.apiculture.example/v1` | `ak_test_…` |

The sandbox has the same surface as production, uses isolated test data, and never sends real notifications.
